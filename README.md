# AI Software Engineer

An AI-powered software engineering assistant that will gradually evolve from a coding chatbot into an autonomous AI agent.

## Phase 1

The first version provides:

- AI chat
- Code generation
- Code explanation
- Debugging
- Code refactoring
- Error explanation
- Documentation generation

## Tech Stack

### Frontend

- React
- Tailwind CSS
- Vite

### Backend

- FastAPI
- Python

### AI

- Google Gemini
